# Plugins Directory

This directory centralizes cross-agent plugins, hooks, and integrations for Herdr pane tracking, OpenChamber orchestration, OpenCode extensions, and Codex tools.

## Included Plugins

| Plugin | Target Agent / Platform | Description |
|---|---|---|
| [`herdr-agent-state`](./herdr-agent-state/) | Hermes, OpenCode, Antigravity | Real-time session identity and lifecycle reporting to Herdr panes |
| [`openchamber`](./openchamber/) | OpenChamber / OpenCode | Multi-project, session branching, model switcher, and scheduler control tool |
| [`opencode`](./opencode/) | OpenCode | Auto-rename sessions and extension utilities |
| [`zammad-mcp`](./zammad-mcp/) | Codex / FastMCP | Codex-compatible plugin package with Zammad ticket triage, PR digest, and Codacy integration |
