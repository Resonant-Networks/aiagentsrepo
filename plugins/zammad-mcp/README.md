# Zammad MCP Codex Plugin

Repo-local Codex plugin package for maintaining FastMCP servers and Zammad integrations.

## Features
- **Manifest**: `.codex-plugin/plugin.json` defining capabilities, categories, and entrypoints.
- **Maintainer References** (`references/`): Curated guidelines on fastmcp design, python typing, and testing boundaries.
- **Associated Skills**: Packaged under `skills/codex-plugins/` (`zammad-mcp-issue-digest`, `zammad-mcp-pr-digest`, `zammad-mcp-quality`).
